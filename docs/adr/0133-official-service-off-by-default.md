# 官方服务默认关闭，用户开启前不出站

`docs/adr/0093` 让官方服务默认开启，首次进入市场页时告知并提供一键关闭，以换取可用的安装统计。本项目是上游 ArcReel 的 fork，内置的官方服务地址属于上游运营方；默认开启意味着用户还没做选择，实例标识就已经随市场页的聚合查询发给了一个不由本项目运营的服务。决定改为**默认关闭**：

- 系统设置 `official_service_enabled` 只有值为 `"true"` 时才算开启；缺这条设置、或为其他任何值都按关闭处理。关闭时 `OfficialServiceGateway.open` 返回 None，不生成实例标识，本地服务端对官方服务零出站。
- 地址仍随版内置，`ARCREEL_OFFICIAL_SERVICE_URL` 的覆盖语义不变；地址为空时开关打开也不出站。
- 用户在市场「设置」Tab 打开「使用官方服务」后，首次进入「浏览」仍显示原有的说明（上报了什么、在哪里关闭），确认后不再提示。

## Considered Options

- **保持默认开启加首次告知**：说明出现时第一次聚合查询已经带着实例标识发出，告知晚于出站，等于替用户做了决定。
- **首次进入市场页时弹窗询问**：需要新的交互与状态，而市场本身不依赖官方服务；放在设置里由用户主动打开即可。

## Consequences

- 取代 `docs/adr/0093` 中「上报默认开启；首次进入市场页时说明」一条与「默认关闭（opt-in）」被否决的理由；实例标识、只报官方源、旁路上报等其余规则不变。
- 默认状态下市场页不显示安装量与评分，分享到官方市场、评分都要求先开启官方服务。
- 安装时官方服务处于关闭状态的条目不会被上报，开启后为它评分会被官方服务以「没有安装记录」拒绝。
