# 免版权素材库只列不用署名的素材，密钥按来源的条款归属

剪辑时除了上传与 AI 生成，还要能直接挑现成的免版权音乐、音效与图片。成片不做署名（没有出处清单，也没有片尾出处画面），所以要求署名的授权不能用。决定如下。

**只收免署名的授权**：CC0、公有领域标记，以及 Pixabay 与 Pexels 自己的授权。CC BY 等要求署名的、以及禁止商用的素材，在请求参数里就过滤掉，解析响应时再核对一次，来源返回了范围之外的授权就丢掉那一条。每条导入的音乐与音效在库里记下 `source: "library"`、授权代号与它在来源站的页面，之后要放宽范围或补做署名时资料还在。

**四个来源，按它们实际提供的内容分工**：

| 来源 | 提供 | 密钥 |
| --- | --- | --- |
| Openverse | 图片、音乐 | 不需要 |
| Pixabay | 图片 | 工作区共用，管理员设置 |
| Pexels | 图片 | 工作区共用，管理员设置 |
| Freesound | 音效、音乐 | 每位成员用自己的 |

Openverse 上免署名的音频，扣掉 Freesound 的条目后，实测只剩维基共享资源里的公有领域音乐录音（多为 OGG）与单词发音录音，所以它只提供音乐、不提供音效，并滤掉 15 秒以下的录音。OGG 与 FLAC 在导入时用随包 ffmpeg 转成 MP3，BGM 库与音效库的格式白名单不变。ccMixter 的曲目几乎都要求署名，不接。Pixabay 没有音乐与音效的接口。Unsplash 要求热链原图地址，与「存进项目再渲染」冲突，不接。

**Freesound 的密钥按成员存**：它的条款不允许把内容转供给没有 Freesound 账号的人，所以不设工作区共用的密钥，表 `stock_source_key` 以 `(来源, 归属)` 存密钥，归属是空串（工作区共用）或成员的账号 id。Agent 不代表某位成员，用不了 Freesound：Agent 能找免版权音乐，要音效时用生成。Openverse 的音频结果也排除 Freesound 的条目，免得绕过这条限制。

**下载地址不信任前端**：导入时按 `(来源, id)` 向来源重取条目，再从它给的地址下载。下载只走 HTTPS，目标主机解析出的地址必须全部是公网地址（内网、环回、云元数据地址一律拒绝，解析不了也拒绝），每一跳重定向都重新校验，单个档案上限 100 MB。请求带上应用名与项目主页作为 User-Agent，维基共享资源会拒绝没有标明身份的请求。

**导入走既有的登记路径**：音乐与音效经 `POST /projects/{name}/stock/import` 登记进 BGM 库与音效库，与上传同样统一音量、按字节登记。图片不另做导入接口：页面经 `GET /stock/image` 取回档案，再走既有的图片上传接口存成资产图，与使用者自己上传的图片同一条路。素材库不提供视频：项目里的视频都是按视频单元生成的，没有放现成视频的位置。
